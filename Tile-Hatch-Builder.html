How the pattern is built

      
Every pattern line is angle, x, y, shift, offset, dash, space. It draws one tile edge, then repeats it: offset is the distance to the next parallel copy, shift slides that copy along the line, and the dash/space pair draws the edge and skips to where the same edge comes round again.

      
Each tile in the repeating cell contributes four lines (bottom, top, left, right). The builder works out the repeat cell for the layout, then for each edge finds the shortest distance before that edge repeats along its own line and the matching offset to the next line. That is the same arithmetic the CADhatch spreadsheet does with hand-written formulas, generalised so it works for herringbone, basketweave and rotated layouts too.

Revit vs AutoCAD files

      
The pattern lines are the same in both. Revit adds a few header lines AutoCAD ignores:

      
    
        
  • ;%UNITS=MM or INCH sets the units of every number in the file.
    • 
        
  • ;%VERSION=3.0 is the file format version.
    • 
        
  • ;%TYPE=MODEL makes it a model pattern, sized in real millimetres, which is what you want for tiles. DRAFTING patterns keep the same printed size at any view scale.
    • 
      

      
AutoCAD reads the *name,description line only, and the file name must match the pattern name.
